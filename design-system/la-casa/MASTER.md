## Web-first update (2026-09-11)

Direction from Mirage: web app before mobile, more 3D motion, more professional,
less white space, no numbered lesson path. Skill queries used:
`"health education learning platform web dashboard" --design-system --variance 6 --motion 6 --density 7`,
`"3d card tilt perspective" --domain style`, `"3d transform tilt hover" --domain gsap`,
plus the project's `redesign-existing-projects` and `high-end-visual-design` skills.

- **Style:** Dimensional Layering (elevation scale `--shadow-e1..e3`, `translateZ` depth)
  with clay-style 3D icon blocks (`.block3d`) — the Claymorphism "soft 3D" cue, kept to
  icons so body surfaces stay clean and professional.
- **3D:** CSS 3D only (no WebGL): pointer-tilt cards with glare (`TiltSurface`), an
  isometric MyPlate hero scene with floating topic blocks (`HeroScene`). Tilt is off for
  touch and reduced motion. The hero float is the one continuous animation — an explicit
  product request; it is decorative, slow, and disabled by `prefers-reduced-motion`.
- **Layout:** fixed navy sidebar at `lg` (1024px+), `max-w-7xl` content; dashboard is a
  bento grid (hero 8/12 + stats 4/12, featured module 2 columns, module cards, story
  banner). Phone keeps header + bottom tab bar.
- **Type:** Plus Jakarta Sans for headings (`--font-display`), Atkinson Hyperlegible Next
  for body. Body 16px at `lg`, 17px on phones.
- **Components:** `src/components/depth.tsx` (TiltSurface, IconBlock, HeroScene, ProgressRing).

## Global Rules

### Color Palette

Tailwind 4 `@theme` tokens in `src/index.css`. Contrast ratios measured against the
surface they sit on.

| Role | Token | Hex | Notes |
|------|-------|-----|-------|
| Primary (fill) | `brand-600` | `#2278BC` | White text 4.7:1 — buttons, header, active states |
| Primary (text on white) | `brand-700` | `#1A5F96` | 6.7:1 — links, emphasis |
| Primary tint | `brand-50` / `brand-100` | `#F2F8FE` / `#E1F0FC` | Backgrounds only; never text below `-700` on these |
| Health green (fill) | `leaf-600` | `#1F7A44` | White text 5.4:1 — "done" states |
| Background | `canvas` | `#F4FAFF` | Page ground |
| Card | `surface` | `#FFFFFF` | |
| Foreground | `ink` | `#10202E` | |
| Muted foreground | `ink-soft` | `#4A6172` | 6.5:1 on white — secondary text |
| Divider | `line` | `#DBEAF7` | 1.2:1 — decorative dividers only |
| Control border | `line-strong` | `#7893A8` | 3.2:1 — inputs and control boundaries (WCAG 1.4.11) |
| Destructive | `danger-600` | `#B91C1C` | 6.5:1; always paired with an icon or words |
| Ring / focus | `brand-500` | `#3593D8` | 3px outline, 2px offset |

**Module accents** (`leaf`, `sun`, `berry`, `aqua`) each have: `-100` tint, `-500`
mark (bars and dots only — never under text), `-800` text on the tint, and a
`solid` fill used under white text or icons: `leaf-600`, `sun-700` (`#9C6400`,
5.0:1), `berry-600`, `aqua-600`. Use `accent(x).solid` from `components/ui.tsx`,
never `accent(x).bar`, for any filled button or badge.

**Storybook paper** (`paper`, `paper-art`, `paper-line`, `paper-ink`, `paper-soft`,
…) is the reading mode's warm ground — only used by `StoryReader` and story cards.

### Typography

- **Font:** Atkinson Hyperlegible Next (headings and body) — the generator's
  healthcare match, in its newer variable cut (200–800) so existing 600/700/800
  weights keep working. Designed by the Braille Institute for low-vision and early
  readers; distinct I/l/1 and O/0; full Spanish accent coverage.
- **Fallback:** `"Atkinson Hyperlegible", ui-sans-serif, system-ui`
- **Base size:** 17px body, 19px lesson copy, line-height 1.6. Nothing under 12px.
- **Loaded in:** `index.html`


## Style Guidelines

**Style:** Minimalism & Swiss Style

**Keywords:** Clean, simple, spacious, functional, white space, high contrast, geometric, sans-serif, grid-based, essential

**Best For:** Enterprise apps, dashboards, documentation sites, SaaS platforms, professional tools

**Key Effects:** Subtle hover (200-250ms), smooth transitions, sharp shadows if any, clear type hierarchy, fast loading

### Page Pattern

**Pattern Name:** Mobile app shell (overrides the generated landing pattern)

- Sticky brand header with language toggle; fixed bottom tab bar (4 tabs — within the ≤5 limit) clearing the home-indicator safe area.
- **Learn** is a serpentine learning path, not a list: modules are checkpoints, lessons are nodes. Nothing is locked.
- Lessons are **one idea per screen** with a step progress bar, a 44px close control, and a single primary action.
- Reading mode (Storybook) intentionally leaves the shell: no tab bar, warm paper ground, larger type.
- Every screen: one `<main id="main" tabIndex={-1}>` so the skip link can land focus.

## Motion

Low-motion system. Tokens in `src/index.css`:

| Token | Value | Use |
|-------|-------|-----|
| `--duration-fast` | 150ms | Press / hover color changes |
| `--duration-base` | 220ms | Card lift, chevron rotation |
| `--duration-slow` | 420ms | Progress fills |
| `--ease-out-soft` | `cubic-bezier(0.22, 1, 0.36, 1)` | Everything that enters |

- Progress bars animate `transform: scaleX()`, never `width`.
- No infinite animation on decorative elements (the path's old bob/pulse was removed). Loading indicators are the only exception.
- One-shot motion only in response to a user action (lesson step `lc-pop`, module-complete confetti).
- `prefers-reduced-motion: reduce` collapses every animation and transition.

## Anti-Patterns (Do NOT Use)

- ❌ Bright neon colors
- ❌ Motion-heavy animations
- ❌ AI purple/pink gradients

### Additional Forbidden Patterns

- ❌ **Emojis as icons** — Use SVG icons (Heroicons, Lucide, Simple Icons)
- ❌ **Missing cursor:pointer** — All clickable elements must have cursor:pointer
- ❌ **Layout-shifting hovers** — Avoid scale transforms that shift layout
- ❌ **Low contrast text** — Maintain 4.5:1 minimum contrast ratio
- ❌ **Instant state changes** — Always use transitions (150-300ms)
- ❌ **Invisible focus states** — Focus states must be visible for a11y

## Pre-Delivery Checklist

Before delivering any UI code, verify:

- [ ] No emojis used as icons (use SVG instead)
- [ ] All icons from consistent icon set (Heroicons/Lucide)
- [ ] `cursor-pointer` on all clickable elements
- [ ] Hover states with smooth transitions (150-300ms)
- [ ] Light mode: text contrast 4.5:1 minimum
- [ ] Focus states visible for keyboard navigation
- [ ] `prefers-reduced-motion` respected
- [ ] Responsive: 375px, 768px, 1024px, 1440px
- [ ] No content hidden behind fixed navbars
- [ ] No horizontal scroll on mobile
